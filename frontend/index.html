Verification Layers

Attendance is only accepted when every layer passes. Even inside the college campus, a wrong building, floor or room means the attendance is not accepted.

🔒

QR / Barcode Identity

Each student gets a unique QR code containing only a safe private token. Scanning it identifies the student instantly. Tampered or unknown QR codes are rejected.

👤

Face Recognition

A real face-embedding comparison verifies the person presenting the QR is the registered student — not face detection, but actual recognition to stop proxy attendance.

🗺

GPS Geofencing

The browser's Geolocation API confirms the student is inside the college area using Haversine distance. GPS checks the campus only — never exact rooms or floors.

📌

Indoor Positioning

BLE / Wi-Fi beacon based building, floor and zone detection with admin-configurable mappings, plus a clearly-labelled demo indoor location mode.

🎓

Classroom Verification

Matches the detected building / floor / room against the timetable for the live class. Wrong location → attendance rejected according to configured policy.

📊

Role Dashboards

Separate student, teacher and admin portals. Attendance history, reports, multi-factor verification records, and CSV export — with role-based security.

How attendance works

Every attempt runs through the full verification pipeline below before a record is written.

Login

Student logs in securely with their account.

Class & QR

Student selects the current class and scans their QR.

Face

Face embedding is compared with the registered template.

GPS

Geofence check confirms the student is on campus.

Indoor

BLE/Wi-Fi zone check finds building, floor, room.

Timetable

Expected location must match the scheduled class.

Duplicate

Repeated marks for the same class are prevented.

Marked

PRESENT is stored with verification records in MongoDB.

Built for three roles

🎓 Student

Own profile, personal QR code, face registration, today's classes, timetable, own attendance percentage and history — never other students' data.

📖 Teacher
